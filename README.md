# Bot Lari

 Shiorun adalah aplikasi bot AI yang dirancang untuk memberikan pengalaman interaktif dan responsif.

## Fitur

- Chat interaktif dengan AI
- Respons cepat dan akurat
- Interface yang user-friendly
- Integrasi mudah

## Instalasi

1. Clone repository ini
```bash
git clone <repository-url>
```

2. Install dependencies
```bash
npm install
```

3. Setup environment variables
```bash
cp .env.example .env
```

4. Jalankan aplikasi
```bash
npm start
```

## Penggunaan

Setelah aplikasi berjalan, Anda dapat mengakses Bot Lari melalui interface yang disediakan dan mulai berinteraksi dengan bot.

## Teknologi

- Node.js
- Express.js
- AI
